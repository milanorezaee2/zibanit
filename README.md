# GEMORIA — Digital Gemstone Museum

موزهٔ دیجیتال سنگ‌های قیمتی، کانی‌ها و نمونه‌های زمین‌شناسی.
پروژهٔ لوکس و بین‌المللی، **بدون قابلیت خرید**؛ فاز اول کاملاً فارسی و RTL.

## وضعیت فعلی

**مرحلهٔ ۰ — برنامه‌ریزی.** هیچ کدی از برنامهٔ اصلی هنوز نوشته نشده است.
کار پس از تأیید سند فنی آغاز می‌شود.

> منبع حقیقت، فایل‌های `*.md` است.

## خلاصهٔ پشتهٔ پیشنهادی

- **Next.js 16** (App Router) + React 19 + TypeScript سخت‌گیر
- **PostgreSQL** — PGlite در توسعه/پیش‌نمایش، Postgres واقعی در تولید (دیالکت یکسان)
- **Drizzle ORM** + مایگریشن‌های SQL قابل بازبینی
- **Tailwind CSS 4** + توکن‌های برند (زمردی، مشکی، طلای عتیقه)
- **next-intl** با `localePrefix: 'as-needed'` — فارسی روی ریشه، انگلیسی/عربی بعداً بدون تغییر URL
- پنل مدیریت جدا از موزه (`/admin`)، احراز هویت اختصاصی با Argon2id + TOTP + RBAC + لاگ حسابرسی

## قواعد غیرقابل‌مذاکرهٔ پروژه

۱. این پروژه **فروشگاه نیست**: بدون سبد خرید، قیمت، پرداخت یا فرآیند خرید.
۲. فاز اول فقط فارسی، با پشتیبانی کامل RTL.
۳. معماری از روز اول آمادهٔ افزودن انگلیسی (LTR) و عربی (RTL) است.
۴. پنل مدیریت از رابط عمومی موزه جدا است.
۵. همهٔ محتوای مهم از طریق پنل مدیریت قابل مدیریت است.
۶. هیچ قابلیتی «پیاده‌شده» اعلام نمی‌شود مگر با معیار پذیرش قابل‌سنجش.
