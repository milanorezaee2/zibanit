# فونت‌های گموریا — منبع، مجوز، و نحوهٔ تعویض

این سند پاسخ یک پرسش است: **چرا این سه خانوادهٔ فونت، از کجا آمده‌اند، و اگر فردا خواستیم عوضشان کنیم چه چیزی باید تغییر کند؟**

> قاعدهٔ حاکم (D-03): فونت‌ها **خودمیزبان** هستند. هیچ درخواستی به CDN، هیچ `next/font/google`، و هیچ وابستگی به شبکه در زمان build یا اجرا وجود ندارد. اگر سرورِ فونت گوگل فردا در ایران کند یا مسدود شود، موزه دست‌نخورده می‌ماند.

---

## ۱. سه نقش، سه خانواده

| نقش | خانواده | وزن‌ها | متغیر CSS | کجا استفاده می‌شود |
|---|---|---|---|---|
| نمایش / تیتر | **Noto Naskh Arabic** | ۴۰۰، ۷۰۰ | `--font-gemoria-display` | `Heading`، تیتر بخش‌ها، نام سنگ، نقل‌قول‌های بزرگ |
| متن / رابط | **Vazirmatn** | ۴۰۰، ۵۰۰، ۷۰۰ | `--font-gemoria-body` | بدنه، جدول، فرم، دکمه، ناوبری، اعداد فارسی |
| لاتین / وردمارک | **Cormorant Garamond** | ۶۰۰ | `--font-gemoria-latin` | فقط `GEMORIA` (وردمارک) و اعداد لاتین تزئینی |

**چرا این ترکیب؟** در `docs/type-specimen.html` نُه خانوادهٔ فارسی در کنار هم و با متن واقعی موزه‌ای سنجیده شد. نسخهٔ نهایی نه «کلاسیک‌ترین» را انتخاب کرد و نه «امن‌ترین»؛ ترکیبی انتخاب شد که سه کار را همزمان انجام می‌دهد: تیترها اقتدارِ نسخهٔ خطی را دارند (نسخ، نه نستعلیق — چون نستعلیق در اندازهٔ کوچک و در رابط کاربری خوانده نمی‌شود)، متن در ۱۴ پیکسل روی کاغذ کرم روشن خوانا می‌ماند (وزیرمتن برای همین ساخته شده)، و وردمارک لاتین با کورمورانت لحنِ کتاب چاپی قرن نوزدهم را می‌گیرد بی‌آنکه به «فروشگاه جواهر» شبیه شود.

## ۲. از کجا آمده‌اند (و چطور بازتولید می‌شوند)

فونت‌ها از بسته‌های `@fontsource/*` روی npm گرفته شده‌اند (نسخهٔ ۵٫۳٫۰)، زیرمجموعه‌های `arabic` و `latin` با `fontTools` ادغام شده‌اند، و نتیجه در `src/fonts/` کامیت شده است.

| فایل | حجم | ترکیب |
|---|---|---|
| `vazirmatn-arabic-latin-400.woff2` | ۳۵ KB | arabic + latin |
| `vazirmatn-arabic-latin-500.woff2` | ۳۶ KB | arabic + latin |
| `vazirmatn-arabic-latin-700.woff2` | ۳۶ KB | arabic + latin |
| `noto-naskh-arabic-400.woff2` | ۶۲ KB | arabic + latin |
| `noto-naskh-arabic-700.woff2` | ۶۳ KB | arabic + latin |
| `cormorant-garamond-600.woff2` | ۲۳ KB | latin فقط (عمدی) |
| **جمع** | **۲۷۲ KB** | |

بازتولید:

```bash
python3 -m venv .venv-fonts && .venv-fonts/bin/pip install fonttools brotli
npm install --no-save @fontsource/vazirmatn @fontsource/noto-naskh-arabic @fontsource/cormorant-garamond
.venv-fonts/bin/python scripts/fonts/merge-subsets.py
npx vitest run tests/fonts.test.ts
```

### چرا ادغام لازم بود؟

نسخهٔ خام `@fontsource` قابل استفاده نبود و دلیلش دقیقاً همان چیزی است که در یک سایت دوزبانه خراب می‌شود:

* زیرمجموعهٔ `arabic` وزیرمتن **هیچ حرف لاتینی ندارد** — هر عدد و هر `Emerald` در فونت جانشین رندر می‌شد؛
* زیرمجموعهٔ `arabic` نوش‌نسخ **علائم نگارشی فارسی را ندارد**: `« » ( ) — / %` و نقطه؛
* اگر `arabic` و `latin` را دو `@font-face` جدا اعلام کنیم، مرورگر گلیف‌به‌گلیف فونت عوض می‌کند و در متن مختلط راست‌به‌چپ/چپ‌به‌راست، کرنینگ و شکل‌گیری حروف می‌شکند.

ادغام، **همان خطوط گلیف** را در یک فایل کنار هم می‌گذارد؛ هیچ حرفی دوباره طراحی نشده است.

### مجوز

هر سه خانواده زیر **SIL Open Font License 1.1** منتشر شده‌اند که بازتوزیع، ادغام و استفادهٔ تجاری را با حفظ متن مجوز و بدون فروش فونت به‌تنهایی مجاز می‌کند. فایل‌های مجوز در بستهٔ اصلی موجودند؛ اگر روزی فونت‌ها را جایگزین کردیم، این بند باید بازبینی شود.

## ۳. ساختار: یک نقطهٔ تعویض

```
src/fonts/*.woff2            ← فایل‌ها (خودمیزبان)
src/app/fonts.ts             ← تنها جایی که next/font/local صدا زده می‌شود
src/config/fonts.ts          ← نقش‌ها، فهرست فایل‌ها، گلیف‌های الزامی، نمونه‌های شکل‌گیری
src/app/globals.css          ← @theme inline: --font-display / --font-body / --font-latin
components/**                ← فقط از کلاس‌های font-display / font-body / font-latin استفاده می‌کنند
```

**هیچ کامپوننتی نام فونت را نمی‌داند.** یک کامپوننت می‌گوید «من تیترم» (`font-display`)، نه «من نوش‌نسخم». برای تعویض فونت نمایشی:

1. فایل woff2 جدید را در `src/fonts/` بگذارید؛
2. در `src/app/fonts.ts` مسیر و `fontFamily` را عوض کنید؛
3. در `src/config/fonts.ts` فهرست `SHIPPED_FONT_FILES` و `REQUIRED_GLYPH_SETS` را به‌روز کنید؛
4. `npx vitest run tests/fonts.test.ts`.

اگر گلیف فارسی جایی کم باشد، مرحلهٔ ۴ **قرمز می‌شود** — نه اینکه در مرورگر کشف شود.

## ۴. آنچه واقعاً آزمایش شده است

`tests/fonts.test.ts` (۱۵ آزمون، روی فایل‌های واقعی woff2 پارس‌شده با `fontkit`):

| آزمون | چه چیزی را ثابت می‌کند |
|---|---|
| وجود و حجم هر ۶ فایل | فونت‌ها واقعاً در مخزن‌اند، نه در CDN |
| جدول woff2 (`wOF2`) | فایل‌ها معتبرند، نه دانلود نیمه‌کاره |
| پوشش گلیف حروف فارسی | `ا ب پ ت ث … گ ل م ن و ه ی` در هر دو خانوادهٔ فارسی |
| پوشش اعداد فارسی `۰۱۲۳۴۵۶۷۸۹` | اعداد صفحه به فونت جانشین نمی‌افتند |
| پوشش اعداد عربی-هندی `٠١٢٣٤٥٦٧٨٩` | آمادهٔ فاز عربی |
| پوشش علائم نگارشی فارسی `« » ٫ ٬ ؛ ؟ ،` و `. ( ) — / %` | همان دلیلی که ادغام لازم شد |
| پوشش لاتین در فونت متن | متن مختلط «Mohs 7.5» می‌شکند نه اینکه به فونت سوم بپرد |
| **نبود** پوشش عربی در کورمورانت | وردمارک لاتین عمداً لاتین است؛ کسی سهواً فارسی در آن نگذارد |
| شکل‌گیری `میزان` با و بدون ZWNJ | نیم‌فاصله در فونت متن واقعاً به شکل درست می‌شکند |
| `.notdef` در نمونه‌های شکل‌گیری | هیچ گلیف ناموجودی در متن نمونه وجود ندارد |

نمونه‌های شکل‌گیری و فهرست گلیف‌ها در `src/config/fonts.ts` نگهداری می‌شوند، پس آزمون و صفحهٔ نمونه از یک منبع می‌خوانند.

## ۵. محدودیت‌های شناخته‌شده

* **نستعلیق نیست.** برای تیتر و متن، نسخ انتخاب شد. اگر در فازی نقل‌قول‌های شاعرانه خواستیم، `Gulzar` گزینه است و در `docs/type-specimen.html` سنجیده شده — ولی به‌عنوان فونت چهارم، نه جایگزین.
* **بدون variable font.** سه وزن ثابت برای متن و دو وزن برای تیتر کافی بود و حجم کل را ۲۷۲ KB نگه داشت. اگر بعداً وزن‌های بیشتر لازم شد، فایل‌ها باید از نو ادغام شوند.
* **کورمورانت فقط ۶۰۰ دارد.** وزن دیگر وردمارک وجود ندارد؛ اگر طراحی خواست، باید افزوده شود.
* **اعداد فارسی در کورمورانت نیست** و نباید استفاده شود؛ همهٔ اعداد فارسی با `font-display` یا `font-body` رندر می‌شوند (این باگ در بازبینی نهایی پیدا و اصلاح شد).
